# W11 green contract set: cases that MUST stay byte-exact GREEN.
#
# This is the mirror image of scripts/loud-contracts.txt:
#   loud-contracts.txt  -> every case MUST exit non-zero (a documented rejection)
#   green-contracts.txt -> every case MUST exit zero with ok=True (byte-exact)
#
# They are deliberately SEPARATE files: mixing them would require the gate to
# know which expectation applies to which row, and a mis-filed row would then
# silently invert its own assertion. Two files, two gates, one meaning each.
#
# scripts/green-gate.ps1 reads THIS file, runs scripts/difftest.ps1 -Case <name>
# and requires ok=True (exit 0). Any failure is a hard gate failure.
#
# Format: one case name per line, optional ' #' note. The matching case
# directory lives under tests/cases/<name>/.

# --- W11 P0-D: decimal GroupBy bucket First/Last ---
# Regression anchor for the header/declaration gap fixed in P0-D: the runtime
# DEFINED il2cpp_linq_grouping_first_dec / _last_dec (via the
# IL2CPP_LINQ_GRP_DEC_OPS macro in linq_map.cpp) but linq_map.h never declared
# them, so `grp.First()` / `grp.Last()` over a decimal bucket emitted
# `il2cpp::il2cpp_linq_grouping_first_dec(...)` and the C++ build failed with
# "is not a member of 'il2cpp'".
#
# This case MUST stay ok=True (byte-exact against the net48 oracle). It must
# NEVER become a LOUD reject and must NEVER fail to compile: either outcome
# means the declaration gap came back.
w11probe-linqgrpdec  # GREEN anchor: P0-D decimal GroupBy bucket First/Last must compile and stay ok=True

# --- QCall P2 public surface: Marshal COM slot / visibility markers ---
# The four public QCalls in the P2 gap set (Marshal.GetStartComSlot,
# GetEndComSlot, IsTypeVisibleFromCom, GetTypedObjectForIUnknown) are not
# "missing": each has a MethodMap arm that emits a transpile-time marker,
# and StackFold resolves it to a constant (StackFold.cs ComStartSlotMarker /
# ComEndSlotMarker / ComTypeVisibleMarker). This case pins the answers:
#   IUnknown interfaces start at slot 3; a 2-method interface ends at 4;
#   a derived 5-method interface ends at 5; a non-interface answers -1;
#   [ComVisible(false)] answers False, the default answers True.
#
# Every typeof argument must be a compile-time constant AND a type defined in
# the transpiled assembly -- an external TypeRef (e.g. typeof(int)) is rejected
# by the folder, see docs/audit/qcall-gap-tiers.md section 2.
comslot  # GREEN anchor: Marshal COM slot + visibility fold must stay byte-exact

# ProbeApartmentFail: the REFUSAL half of the Thread apartment surface.
# Net48 throws ThreadStateException from BOTH SetApartmentState and
# (surprisingly) TrySetApartmentState on a started thread, and
# ArgumentOutOfRangeException for a value outside the enum. The 5 lines must
# stay byte-exact. NOTE the scope limit recorded in the case header: the
# STA-ACCEPTING paths are excluded because the net48 oracle cannot format
# exceptions after accepting an STA request on this host (no STA pump).
probe-apartment-fail  # GREEN anchor: apartment refusal channels must stay byte-exact

# ProbeExcBase: a user-defined exception must sit in the exception subtree.
# A user exception's base lives in the BCL, which the loader does not link, so
# the descriptor used to say baseClass = nullptr and is Exception answered
# False. The 13 lines below pin the whole matrix: direct subclass, two-level
# user chain, modelled BCL base (ArgumentException), unmodelled BCL base
# (InvalidOperationException -> falls back to System.Exception), a plain class
# keeping its null root, and the catch path.
probe-excbase  # GREEN anchor: exception base chain must stay byte-exact

# ProbeCatchF6a: a catch handler whose FIRST instruction consumes the entry.
# When the caught object is used only by an s/is expression, Roslyn tests
# the entry directly (brfalse/brtrue) -- and drops the isinst entirely when the
# static type makes the conversion infallible. Without those branch opcodes in
# OpcodeConsumesStack no entry was pushed and the whole method failed to
# transpile ("Stack empty."). The two lines below cover both as-only and
# is-only shapes.
probe-catchf6a  # GREEN anchor: catch entry consumed by a leading branch must fold

# ProbeUserExcMsg: a user-defined exception keeps the message its ctor was given.
# The throw-site carrier is populated from the ctor arguments captured at the
# allocation, but that capture was gated on "is this a BCL exception name",
# which a user type can never satisfy -- every throw carried the placeholder
# text. The three lines below cover a direct subclass, a two-level chain, and a
# non-exception class (the guard against over-broadening the capture).
#
# SCOPE: this pins the INLINE throw/catch path only. Reading the message after
# the exception crossed a method boundary still answers the carrier's own type
# name (the open catch-carrier defect, docs/audit/half-wired-nonp0.md).
probe-userexcmsg  # GREEN anchor: user-exception message must stay byte-exact
