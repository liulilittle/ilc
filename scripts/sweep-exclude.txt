# key under an object/interface TKey uses the same culture collation) and

# BATCH4: loud-p0-17-zipres-loud is now WIRED (the narrow 1/2-byte Zip result

# --- W11 P0-A: Console DEVICE surface LOUD anchors (controlled set = scripts/loud-contracts.txt) ---
# These four are the only coverage of the Console device surface. They are
# registered HERE as well as in loud-contracts.txt for one reason: run-tests.ps1
# scans the FULL pool and has no "LOUD contract" escape, so without this entry a
# full run would count them as permanent FAILs. The "LOUD contract" note keeps
# difftest.ps1 on its normal path (difftest.ps1:181 skips only entries whose line
# does NOT match 'LOUD contract'), so loud-gate.ps1 still executes them and
# verifies they reject. Silencing is therefore impossible: the failure is caught
# by loud-gate, and the contract is listed in loud-contracts.txt.

w11probe-clear     # LOUD contract: W11 P0-A Console.Clear() must reject, never emit icall_console_clear
w11probe-setters   # LOUD contract: W11 P0-A Console setters (ForegroundColor/BackgroundColor/Title/CursorLeft/CursorTop/CursorVisible) must reject
w11probe-getters   # LOUD contract: W11 P0-A Console getters (Title/colors/cursor/window+buffer) + SetCursorPosition/ResetColor/Beep(f,d) must reject
