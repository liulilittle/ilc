## 1. P0-2 常量局部传播（StackFold.cs）

**规则**：方法内"恰好一次 stloc 且无 ldloca/ldloca_s 取址"的局部，其 stloc 值为 `IntConstExpr` 时记入 `locConst` 表；后续 `ldloc` 直接替换为常量；全部读取被替换后删除死 stloc（否则生成代码出现写后无读的局部，触发 -Wunused-but-set-variable）。

**安全边界（等价性论证）**：
- 单赋值保证无二次覆盖；无取址保证无 byref 修改路径。
- `locConst` 在**每个标签（汇合点）**与**每个异常 handler 起点**清空——这些点可从"绕过该赋值"的路径进入（异常路径/分支跳转），局部值不可知。handler 起点来自 `ctx.ExceptionRegions.HandlerOffset`（catch/finally/fault 一律清空；finally 在 M3 中经双路发射，正常路径与异常路径都必须正确）。
- 死存储删除保守判定：仅当该名字在语句表中**恰好一个**赋值（避免与 join 临时槽 tN 同名误删）+ **零残留 LocExpr 引用**（StmtReferencesName 遍历全部语句表达式位，复用 ReferencesTarget）。
- 链式传播自然发生：`stloc x,5; ldloc x; stloc y,<x 值>`——ldloc 在入栈时已替换为常量，stloc y 记录到同一常量。
- 连锁收益免费：替换后分支条件变常量 → 发射期既有机制（`CodeGenerator.cs:589` 常量分支定死 + EmitBody 可达性分析死块消除）自动触发，零新增代码。

**unit 测试**（tests/unit/StackFoldTests.cs，6 个）：
`Fold_ConstProp_ChainFoldsToConstant_AndDeadStoreRemoved` / `Fold_ConstProp_TwoStores_NoPropagation` / `Fold_ConstProp_LabelJoin_NoPropagation` / `Fold_ConstProp_AddressTaken_NoPropagation` / `Fold_ConstProp_ChainAcrossTwoLocals` / `Fold_ConstProp_HandlerStart_NoPropagation`

## 2. P0-1 代数恒等式（Normalize.cs）

**规则表**（自底向上重写全部 Stmt 表达式位：AssignStmt.Value / RetStmt.Value / BranchStmt.Condition / CallStmt.Args / FieldAssignStmt.Object+Value）：

| 规则 | 条件 | 等价性论证 |
|---|---|---|
| `x+0→x`、`0+x→x`、`x-0→x`、`x*1→x`、`1*x→x` | 任意表达式（保留求值） | 恒等式，mod 2^32 下恒成立；求值次数不变 |
| `0-x→-x` | 任意表达式（保留求值） | 0-x ≡ -x (mod 2^32)；与既有 Neg 发射同型（INT32_MIN 的 C++ 溢出 UB 为既有模式，任务卡明列此项） |
| `x*0→0`、`x&0→0` | **仅纯算术子树** | 移除求值；FieldExpr 可抛 NRE、Div/Rem 可抛除零——任务卡"IR 纯表达式"对 call 成立（StackFold 已物化为 temp）但对 FieldExpr/Div 不成立，保守处理 |
| `x^0→x`、`x|0→x`、`x&(-1)→x`、`x<<0→x`、`x>>0→x` | 任意表达式 | 保留求值；x&0xFFFFFFFF ≡ x (mod 2^32) |
| `x-x→0` | 结构相等 + 纯算术 | 自减恒 0（无溢出可能）；dup 同实例经 ExprEquals 参考相等兜底 |
| `-(-x)→x`、`~~x→x` | 任意表达式 | -( -x ) ≡ x (mod 2^32)，含 INT32_MIN |
| `(x+c1)+c2→x+(c1+c2)`（同 op） | Add/Mul/And/Or/Xor | 交换+结合在 mod 2^32 下成立；合并常量经 TryFoldInt32（int64 中间值再回绕——任务卡"int32 回绕"要求）；先常量右置规范化（`c op x → x op c`）使 `(2+x)+3→x+5` 也成立 |
| 双常量折叠 `5+7→12` | 全部二元/一元 | 复用 TryFoldInt32（internal 化，单一回绕实现——DRY） |
| `x==x→1`、`x>x→0`、`x<x→0`、无符号变体→0 | 结构相等 + 纯算术 | 移除双侧求值仅限纯子树；`x!=x` 经 Not(Ceq(x,x))→Ceq(1,0)→0 自动连锁 |
| `x/1` 等除法恒等 | **不做** | 除零异常语义 + INT32_MIN/-1 回绕，研究文档明令不做 |

**顺序**：子节点重写 → 常量右置（交换律 op 且左常量右非常量）→ 双常量 TryFoldInt32 → 恒等式 → 条件恒等 → null 折叠 → 同类合并。

## 3. P0-3 null 比较折叠（Normalize.cs）

| 规则 | 条件 |
|---|---|
| `null==null→1`、`null!=null→0`（cgt/clt 变体→0） | 双 NullExpr，恒成立 |
| `obj==null→0`、`obj!=null→1`（clt 变体→0） | obj 在**已知非空集**中 |

**已知非空集**：直线流 AssignStmt 追踪——`NewObjExpr`（il2cpp_object_new）/ `StringConstExpr`（ldstr）/ `newarr_*`、`box_*` CallExpr（本运行时分配永不返回 null）+ LocExpr 链式拷贝（`t1 = t0`）；在**标签与 handler 起点清空**（与 const-prop 同规则），重赋值即失效。与帧根优化代理零共享状态（各自独立保守分析；如冲突可独立退化为仅常量部分）。

## 4. 等价性总论证

1. 全部规则在 int32 无符号回绕（mod 2^32，.NET unchecked 精确语义）下恒成立——与 TryFoldInt32/Wrap32 同一语义模型，合并常量用 int64 中间值再回绕（`ConstantMerge_WrapSemantics` 测试钉死：`(x+int.MaxValue)+1 → x+0x80000000` 非 int64 数学）。
2. 求值移除型规则（x*0/x&0/x-x/比较恒等）限定 `IsPureArithmetic`（LocExpr/IntConstExpr/NullExpr + 无 Div/Rem 嵌套）——任何可能抛异常的子树（FieldExpr→NRE、Div/Rem→除零）不被移除，异常语义逐字节保持。
3. 求值保留型规则对任意表达式安全（读/写次数不变）。
4. 常量传播的安全边界（单赋值/无取址/标签与 handler 失效）为"可能错误折叠"提供了形式化排除。
5. 分支定死与死块消除复用发射期既有机制（EmitBody 可达性 + 常量分支），零新增控制流逻辑。
