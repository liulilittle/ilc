# M4 P/Invoke + Marshal + icall 平台层 + C API + 四态产物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 M3 运行时之上实现平台互操作层：P/Invoke（DllImport 静态/动态绑定 + 参数 marshalling + SetLastError）、Marshal 类基础（icall 化）、icall 平台层扩展、C API 导出（il2cpp_*）、四态产物（EXE/DLL/SO/静态库）+ [UnmanagedExport] 托管方法原生导出，使调用 OS API 的 C# 程序经转译后与 .NET Framework 4.8 参考输出逐字节一致。

**Architecture:** 转译器识别 [DllImport] 特性 → 生成原生导入声明（GetProcAddress/dlsym 惰性解析 + 编译期静态绑定两种路径）；P/Invoke 层（调用约定/CharSet/参数 marshalling 编译期生成）；导出层 = C API（il2cpp_* 手写导出）+ [UnmanagedExport] 托管方法 thunk（编译期生成 + 异常边界防护 + 惰性自举）；CMake 生成四态配置。

**Tech Stack:** C# 8 / .NET 8（转译器）；C++17（运行时，GCC 7.5 兼容基线）；CMake ≥3.10；三编译器（MSVC/MinGW/WSL GCC7.5）

**设计文档:** `docs/superpowers/specs/2026-08-02-il2cpp-design.md`（§6 P/Invoke/Marshal/C API/导出契约）
**用户铁律:** `docs/REQUIREMENTS.md`（2d 自研/2e 性能/2h 全英语）

## Global Constraints

（抄自 spec + M1-M3 经验，M4 阶段生效）
- 零 JIT；零第三方依赖；C++17 仅 + GCC 7.5 兼容基线；CMake 3.10 基线
- 引用语义 = 裸 GC 指针（追踪式），严禁 shared_ptr/引用计数/手写 free
- **导出契约（硬性限制）**：导出函数仅限静态方法 + blittable 标量或 buffer（byte*+长度）；对象/string/数组/struct 禁止直接跨边界（违反即编译拒绝）
- 生成代码：全英语超详细注释 + 列对齐 + 4 空格缩进 + 确定性
- 三编译器验证：每任务三编译器编译零错误；e2e 用例双跑逐字节一致
- 任何代码变更后编译零错误（C0）；TDD 红绿循环；CI 一键全绿
- **M3 交接项**：① P/Invoke 需异常边界防护（thunk 内 try/catch → 错误码 + il2cpp_get_last_exception）；② icall 平台层对齐（Console 已支持，Environment/File 等扩展）
